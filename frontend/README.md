# Frontend

Aplicacion de Booking Travel Agency construida con Next.js.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Entorno

Crear `frontend/.env.local` con:

```bash
NEXT_PUBLIC_API_URL=http://localhost:4000
```

## Estado

El frontend ya tiene login y dashboard inicial, pero todavia usa datos mockeados en varias vistas y necesita integrarse mejor con la API antes de escalar modulos.
